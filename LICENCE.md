## 🧩 About

**Helldivers 2 Overlay Menu** is a curated list of Helldivers 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, stratagem viewer, squad panel notes
- **Quality-of-Life Helpers** — loadout catalog, armor notes, overlay config manager
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Stratagem Panel — review stratagem codes on screen
- Mission Map Notes — overview of objectives and poiints of interest
- Loadout Notes — save and review armor and weapon setups
- Playback Notes — record and review mission runs

### Wallhack
- Armor Catalog — browse armor sets, capes, and colors
- Warbond Notes — organize unlock progress notes
- Hud Layout — adjust overlay positions for visibility

### Aimbot
- Squad Panel Notes — study team composition
- Ping Helper — quick visual markers for study
- Config Presets — save overlay layouts for study sessions
